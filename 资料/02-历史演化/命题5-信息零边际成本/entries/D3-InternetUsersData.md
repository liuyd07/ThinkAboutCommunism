# D3: 全球互联网用户增长数据

## 数据源

### 1. World Bank / ITU — Individuals Using the Internet (% of population)

- **指标代码**：IT.NET.USER.ZS
- **来源**：International Telecommunication Union (ITU) World Telecommunication/ICT Indicators Database
- **URL**：https://data.worldbank.org/indicator/IT.NET.USER.ZS
- **覆盖**：1990–2024/2025

关键数据点（全球%人口）：
| 年份 | 互联网用户（每100人） |
|------|----------------------|
| 1990 | 0.05 |
| 1995 | 0.68 |
| 2000 | 6.72 |
| 2005 | 15.6 |
| 2010 | 28.5 |
| 2015 | 39.9 |
| 2020 | 59.3 |
| 2023 | 67.4 |

### 2. Our World in Data — Number of Internet Users

- URL: https://ourworldindata.org/grapher/number-of-internet-users
- 数据源自ITU/World Bank
- 1990年：约250万用户
- 2021年：约50亿用户
- 30年内用户规模增长了约2000倍

### 3. FRED — ITNETUSERP2WLD

- URL: https://fred.stlouisfed.org/data/ITNETUSERP2WLD
- 圣路易斯联储整理的World Bank数据

## 与命题5的关联

互联网用户的指数级增长是"更多用户→更多数据→更好算法→更多用户"这一数字正循环的基础。从1990年不足全球人口0.1%到2023年超过67%，互联网的普及使数据网络效应呈数量级放大。

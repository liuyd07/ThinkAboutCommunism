# D1: 摩尔定律晶体管密度历史数据

## 数据源

### 1. Rupp (2022) — Microprocessor Trend Data

- **维护者**：Karl Rupp（计算科学家）
- **存储**：GitHub — https://github.com/karlrupp/microprocessor-trend-data
- **覆盖时间**：1971–2021
- **指标**：每微处理器晶体管数（取各年份最高值）
- **文件**：`50yrs/transistors.dat`

关键数据点：
| 年份 | 晶体管数 |
|------|---------|
| 1971 | ~2,300 |
| 1974 | ~5,000 |
| 1980 | ~29,000 |
| 1990 | ~1,200,000 |
| 2000 | ~42,000,000 |
| 2010 | ~2,300,000,000 |
| 2021 | ~58,200,000,000 |

平均倍增时间：~2.03年，极其接近Moore的预测。

### 2. Our World in Data 可视化

- URL: https://ourworldindata.org/grapher/transistors-per-microprocessor
- 数据源自Rupp，经Our World in Data处理
- CSV下载: https://ourworldindata.org/grapher/transistors-per-microprocessor.csv

### 3. Wikipedia — Transistor Count

- https://en.wikipedia.org/wiki/Transistor_count
- 包含193个微处理器（1971-2020）的晶体管数表

## 与命题5的关联

摩尔定律是数字正循环的物质基础——每18-24个月计算能力翻倍，同时单位成本呈指数级下降。这验证了命题5的核心前提：数字技术以指数速度改进，远超物质经济中的线性改进速度。

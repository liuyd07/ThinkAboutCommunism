# P10第二轮：信息如何改变生产循环

信息的特殊作用是：一个经过验证的设计可以被许多设备和成员反复调用，而不必重新完成全部发现劳动。它由此降低协调、试错和复制劳动，并改变P08机器网络的投入系数。

但执行链仍是：

```text
问题与经验 → 研究劳动 → 可编码知识 → 通信与存储设备
→ 机器或成员解释执行 → 实体过程改变 → 反馈与维护
```

任何一层失效，数字副本都不能独立形成使用价值。

## 第二轮命题

> 可编码信息具有低边际复制成本，能够把一次知识劳动的成果扩散到大量生产节点，从而降低协调和复制成本；但其生成、验证、存储、传输、执行和维护仍依赖劳动、能源、硬件与组织。

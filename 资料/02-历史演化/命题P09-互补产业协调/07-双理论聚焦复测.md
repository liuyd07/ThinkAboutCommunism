# P09 双理论聚焦复测：协调优势来自降低全环失配而非消灭节点

## 聚焦命题与循环位置

高互补、专用、网络化且有建设时序依赖的产业，局部节点各自扩张不能保证全环有效返回；系统级接口、容量与时序协调可降低闲置、缺口和多节点独立优化损失，但不必采用全产业链共同所有。

若节点能力为 `k_n`，全环服务常受瓶颈 `min(k_n/c_n)` 限制。把非瓶颈节点继续做大只增加闲置，补齐瓶颈才能提高 `R` 和 `g`。

## 四轮对抗

1. **循环攻击——价格能自动引导瓶颈投资。** 在可替代、短建设周期和价格可信时成立；不可逆专用投资、共同标准和先后建设问题仍可能使各方等待。
2. **速率攻击——统一协调也会制造巨大共同错误。** 成立。协调收益须扣除信息延迟、锁定和代理损失；因此只在共同约束的最小有效层级统一。
3. **组织传导攻击——私人垂直一体化同样高效。** 这否定“协调优势必然要求公有制”，不否定系统协调。竞争会选择能减少全环失配的产权或契约组合，而非固定标签。
4. **边界攻击——模块化网络节点更多却更有韧性。** 标准化降低有效耦合，把协调重点转到接口制定、兼容和替代路径；节点数不是协调强度指标。

## 结论

P09 保留但严格中性化：公有制可能扩大共同核算边界，资本主义企业也可通过一体化实现协调；哪种形态产生速率优势，取决于全环失配下降是否大于集中信息和权力成本。

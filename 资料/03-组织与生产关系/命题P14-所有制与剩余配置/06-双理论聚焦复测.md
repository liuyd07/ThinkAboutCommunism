# P14 双理论聚焦复测：所有制通过实际控制链影响净返回

## 聚焦命题与机制

所有制是一束排除、信息、决策、任免、剩余索取、转让和损失承担权。它不直接生产产品，而是通过决定谁选择维护、投资、试验、生活供给和排他权防卫，改变生产循环的 `R-D` 与风险分布。

比较组织形态时，应追踪实际控制链及其对长期 `g` 的影响，不能用“公有”“私有”“合作”名称代替机制。

## 四轮对抗

1. **循环攻击——经营者而非所有者决定生产。** 这证明权利束分离；任免、融资、收益和破产承担仍约束经营者，必须追踪代理链。
2. **速率攻击——同一所有制绩效差异巨大。** 成立，所有制不是充分条件。速率还取决于技术、竞争、信息、成员能力和治理。
3. **组织传导攻击——高增速私企可把损失转嫁公共部门。** 局部 `g` 可能建立在公共补贴、劳动损耗或生态外部化上；扩大边界后重算。转嫁能力本身可形成竞争优势，但不等于整体生产力提高。
4. **边界攻击——员工持股就是共同控制。** 收益分享不等于信息、任免和重大投资权；名义公有也不等于成员可执行控制。

## 结论

P14 保留。所有制只有经实际权利结构改变剩余用途、信息和损失承担，才进入生产循环与速率解释；这为 P19 讨论公有制提供条件，而非预设结论。

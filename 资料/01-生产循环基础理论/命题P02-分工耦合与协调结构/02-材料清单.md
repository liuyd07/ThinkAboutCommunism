# P02 材料清单

1. OECD, *Risks and opportunities of reshaping global value chains*：供应链风险不能仅由投入产出暴露判断，还取决于替代性、互补性、运输集中和投资品依赖；能源占成本小却可能完全阻断生产。https://www.oecd.org/en/publications/economic-policy-reforms-2023_9953de23-en/full-report/component-6.html
2. OECD, *Global value chain dependencies under the magnifying glass*：外部暴露和链长提高依赖，汽车与 ICT 的地理供应集中会放大风险。https://www.oecd.org/en/publications/global-value-chain-dependencies-under-the-magnifying-glass_b2489065-en.html
3. World Bank, *Global Value Chain Development Report 2019*：标准化、模块化和数字化使复杂技术更可扩散，降低进入所需研发、学习和互补技能。https://documents1.worldbank.org/curated/en/384161555079173489/pdf/Global-Value-Chain-Development-Report-2019-Technological-Innovation-Supply-Chain-Trade-and-Workers-in-a-Globalized-World.pdf
4. World Bank 关于模块生态系统研究：标准接口形成“薄交叉点”，模块生产者可独立扩展，但仍需处理接口例外。https://documents1.worldbank.org/curated/en/099506109062231415/pdf/IDU0d48d91a80b1a50484809e1d0ce3d0b9fc07f.pdf
5. World Bank, *World Development Report 2025: Standards for Development*：标准是跨组织协调、交换和技术扩散工具，同时也体现制定权。https://www.worldbank.org/en/publication/wdr2025
6. OECD 疫情供应链研究：统一标准可提高投入替代性，数字系统、压力测试和多样化增强韧性；简单回流会损失专业化收益。https://www.oecd.org/content/dam/oecd/en/publications/reports/2021/02/global-value-chains-efficiency-and-risks-in-the-context-of-covid-19_e838d87a/67c75fdc-en.pdf

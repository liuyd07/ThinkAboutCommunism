# 资料文件夹说明

本文件夹按学术专著的 11 个核心命题组织佐证材料。

## 目录结构

```
资料/
├── 01-生产循环基础理论/
│   └── 命题1-正反馈决定生产力/      ← ch1-6: 生产力=正循环产生新增能力
│       ├── 正面论证/                  ← 支持命题的文献、数据
│       └── 反面论证/                  ← 挑战命题的文献、反例
├── 02-历史演化/
│   ├── 命题2-农业光合天花板/         ← ch7: 农业受限于实时光合作用
│   ├── 命题3-工业革命与正循环/       ← ch8-9: 煤-钢-机械正循环
│   ├── 命题4-能源升级与循环规模/     ← ch9: 电力/石油使循环规模跃迁
│   ├── 命题5-信息零边际成本/         ← ch10: 数字正循环
```

## 材料来源要求

- 学术期刊论文（需标注 DOI 或期刊卷期页码）
- 官方统计数据集（World Bank, UN, IEA, Maddison Project 等）
- 学术专著（需标注出版社、年份、ISBN）
- 权威研究报告（OECD, IMF, World Bank 报告）
- 历史经济数据（英国煤炭产量、苏联工业增长等，需标注原始来源）

## 文件命名规范

```
[序号]-[类型]-[内容简述].md
```

类型前缀：`lit` 文献, `data` 数据, `chart` 图表, `case` 案例, `note` 笔记

示例：`01-lit-EROI历史趋势综述.md`

# 生产循环可测量与制度比较框架

> 本文件是《生产循环论》的技术底座。正文继续使用有向环、分流阀和组织竞争等直观表达；本文件负责规定如何测量、什么结果构成反例，以及怎样比较不同组织制度。

## 一、模型解决什么问题

本框架针对五个薄弱点：

1. 防止用事后成功定义“有效返回”；
2. 防止把不同产品强行加总成单一物质量；
3. 区分技术可行能力、组织实际实现和竞争结果；
4. 区分组织影响生产力与生产力反过来改变组织；
5. 把公有制优势改写为与其他协调方式可比较、可反驳的命题。

## 二、测量单位：只评估当前循环的关键返回产品

### 1. 不评估全部社会产品

对一个明确的生产循环 `c`，先声明它要再生产的关键产品集合：

`J_c={钢材、电力、机器服务、运输服务、特定技能……}`

集合只包含实际返回该循环、决定下一周期能否继续运行或扩大的产品和能力。食品、艺术、一般消费品等终端产品，只有在当前研究明确考察其对劳动能力补偿的部分时才进入；与本循环无关的其他产品不参加循环增益计算。

因此，本书不计算“所有社会产品增长率”，也不把一吨钢、一度电和一次医疗服务自然加总。

### 2. 分类单周期增量

对每一类关键产品 `j∈J_c`，分别记录：

- `q_(j,t)`：周期开始时可用于该循环的有效数量；
- `b_(j,t)`：本周期由循环形成、可返回下一周期的合格数量；
- `a_(j,t)`：维持下一周期同等活动规模所需的数量；
- `d_(j,t)`：无法继续使用的折旧、损坏和失配数量；
- `u_(j,t)`：从其他组织或外部系统净输入的数量。

该类产品由本循环形成的净增量为：

`Δq_(j,t)=b_(j,t)-a_(j,t)-d_(j,t)`

如果研究组织的实际可用存量，则另写：

`Δq^available_(j,t)=b_(j,t)+u_(j,t)-a_(j,t)-d_(j,t)`

两式必须分开。外部输入可以提高本组织下一周期的能力，但不能冒充该组织内部循环的复制结果。

### 3. 分类增益率

在同一规格、质量、地点和周期下：

`g_(j,t)=Δq_(j,t)/q_(j,t)`

这就是某一类关键产品经过一个循环周期后的增益率。每类产品分别报告，不追求天然统一的总增长率。

当研究一套生产活动能否按同一比例扩大时，才定义平衡扩张率：

`g_c^F=min_(j∈J_c) g_(j,t)`

它由最先成为瓶颈的关键返回产品决定。该最小值不是全部社会产品的评价，只是当前循环在既定技术比例下能够同步扩张的上限。

如果各节点不需要同比扩张，则保留完整增益向量：

`g_c=(g_1,g_2,…,g_m)`

并直接报告哪个节点扩大、哪个维持、哪个收缩。

## 三、分类投入产出与物质可行性

设：

- `A_c`：当前循环各项生产活动对关键返回产品的分类投入；
- `B_c`：这些活动形成的分类合格产出；
- `x`：各活动的规模；
- `N_cx≤n̄`：自然资源、生态、劳动时间或其他外部边界。

简单再生产的物质可行条件为：

`B_cx≥A_cx`

给定比例的扩大再生产条件为：

`B_cx≥(1+g)A_cx`

所有不等式均按 `J_c` 中每一类产品逐项判断。任何关键产品不足，平衡扩大就不能实现；非关键终端产品增加不能弥补钢材、电力、设备或运输等瓶颈。

该模型解决的是物质可行性，不直接评价福利、价格或政治目标。

## 四、可行速率、实现速率和组织损失

### 1. 技术可行速率

`g_c^F` 表示在既定技术、资源、设备和生态约束下，当前循环能够实现的分类平衡扩张上限。

它不等于现实增长，也不说明应当追求该上限。

### 2. 组织实现速率

现实组织会产生协调、信息、代理、锁定和冲击损失。对每类关键产品分别写：

`g_(j)^A=g_(j)^F-l_(j,C)-l_(j,I)-l_(j,P)-l_(j,L)-l_(j,X)`

- `l_C`：规格、容量、时序和接口失配；
- `l_I`：信息延迟、隐瞒和预测错误；
- `l_P`：代理、寻租、权力维护和软预算损失；
- `l_L`：技术锁定、垄断入口和路线退出困难；
- `l_X`：冲击、恢复时延和迟发损耗。

不要求把这些损失货币化。可以分别用停机时间、报废量、维护积压、交付延迟、未完工程、故障恢复时间和替代路线数量测量。

### 3. 可行—实现缺口

`Γ_(j)=g_(j)^F-g_(j)^A`

组织形态的生产力作用，首先表现为扩大或缩小各类关键产品的可行—实现缺口，而不是凭所有制名称直接增加生产力。

## 五、组织与生产力共同演化

单向决定论改为双向反馈：

`O_t→Γ_(t+1)→g_(t+1)^A`

`g_t^A,Z_t,S_t→O_(t+1)`

其中：

- `O_t`：控制权、协调方式和组织边界；
- `Z_t`：技术结构；
- `S_t`：稀缺、专用性和外溢结构。

完整机制为：

```text
技术和稀缺结构变化
→ 旧组织暴露新的瓶颈
→ 组织改革、联合或分裂
→ 可行—实现缺口变化
→ 分类产品发展速率变化
→ 竞争能力差距变化
→ 组织被模仿、吸收、依附或淘汰
```

历史论证必须区分：组织改革先发生，还是生产率增长先创造了组织改革条件。

## 六、从发展速率到组织选择的三段机制

### 1. 能力差距

对可比的关键能力 `j`：

`Δln(q_(i,j)/q_(k,j))≈g_(i,j)^A-g_(k,j)^A`

它只说明能力差距的方向。

### 2. 竞争转化

生产能力必须经组织转化为财政、补给、市场、技术扩散、人口吸纳、防卫和联盟能力：

`p_i=C_iq_i`

其中 `C_i` 是竞争转化结构。高生产能力不保证每个竞争领域都能胜出。

### 3. 制度选择

只有能力差距转为竞争压力后，才可能出现：

- 模仿；
- 改革；
- 联合；
- 兼并；
- 依附；
- 吸收；
- 退出。

因此理论预测的是制度改变概率和方向，不是每场竞争的必然胜者。

## 七、固定三层分析边界

每个案例在研究前声明：

1. **组织边界**：企业、国家或合作组织自身；
2. **竞争边界**：相互争夺资源、市场和成员的组织集合；
3. **社会—生态边界**：包含劳动者、消费者、外围地区、资源存量和污染转移。

同一活动可以在组织边界内提高能力，在竞争边界内形成优势，同时在社会—生态边界内造成净损耗。三种结论并存不构成矛盾，但不得在同一推导中临时换边界。

## 八、产能分流采用活动效果向量

通俗正文继续使用：

`Y=M+E+X+C+H+W`

严格分析不把活动强制归入唯一类别，而对活动 `a` 记录：

`y_a=(m_a,e_a,x_a,c_a,h_a,w_a)`

同一医院既可改善生活，也可维护劳动能力和形成医学知识；同一军工研发既可能形成技术选项，也可能增加控制能力和毁损风险。

只有明确分配规则时，各维度才能加总为账户；否则只报告效果向量，避免重复计算。

## 九、创新采用阶段门而非虚假成功概率

创新分成：

```text
探索 → 验证 → 配套 → 复制
```

### 探索门

- 路线是否独立；
- 是否允许局部失败；
- 是否记录失败信息；
- 是否存在停止规则。

### 验证门

- 原型能否重复完成预定功能；
- 结果是否适用于声明的环境；
- 是否暴露新的资源和维护要求。

### 配套门

- 原料、设备、人员、标准和接口是否具备；
- 是否需要同步改造其他循环节点。

### 复制门

- 单位复制劳动是否下降；
- 是否形成维修和更新能力；
- 是否产生可重复的分类产品增量；
- 是否实际改变 `A_c`、`B_c` 或各类 `g_j^F`。

探索预算在跨过复制门前不计为已经实现的生产返回。失败信息只有在被记录、传播并改变后续选择时才形成知识效果。

## 十、制度总损失比较

对制度安排 `O`，不直接比较“公有”或“私有”，而比较：

`L(O)=L_C+L_I+L_P+L_E+L_L`

- `L_C`：协调失配；
- `L_I`：信息和共同错误；
- `L_P`：代理、寻租和责任稀释；
- `L_E`：劳动、生态和链外成本外部化；
- `L_L`：垄断和技术锁定。

| 制度安排 | 可能降低 | 可能增加 |
|---|---|---|
| 市场交易 | 集中信息负担、单点错误 | 外部化、投资等待、多重加价 |
| 私人一体化 | 专用资产要挟、内部协调失配 | 链外外部化、垄断和内部官僚化 |
| 长期合同 | 投资不确定性 | 锁定、重谈和执行成本 |
| 公共监管 | 外部化和垄断 | 信息不足和监管俘获 |
| 合作所有 | 成员代理损失 | 决策成本和融资约束 |
| 国家所有 | 跨期、跨部门协调损失 | 代理链、软预算和共同错误 |
| 实质社会公有 | 社会外部化和分流权分离 | 偏好聚合、信息和责任稀释 |

公有制优势成立的条件是：扩大共同控制后减少的协调、地租和外部化损失，大于新增的信息、代理和共同错误损失。它是比较命题，不是从“大生产”直接得到的定义结论。

## 十一、积累体制采用事前二维分类

### 1. 控制对象

- 自然或制度稀缺权；
- 一个或少数战略存量；
- 可复制生产能力；
- 全社会共同生产条件。

### 2. 剩余用途

- 维护或复制排他权；
- 增加战略对象存量；
- 建设新增能力；
- 承担探索风险；
- 改善终端生活。

收入来源、组织身份、用途和绩效分别记录。地主把地租投入工厂，是“地租来源＋能力建设用途”；工厂失败不把该用途事后改名为地租。资本企业购买入口封锁，是“资本组织＋地租化用途”；后续绩效另行判断。

## 十二、描述层和规范层

### 描述层

回答哪些生产循环可维持、哪些组织实现速率更高、稀缺变化怎样推动集中、分散和地租化。

### 规范层

公开声明价值前提：人的生活不是生产工具；受决策影响者应拥有相应控制权；当前组织不得无限把损耗转嫁给外围和未来世代。

生产循环理论说明共同控制在什么条件下可能更有效；民主、自由和代际责任说明共同控制为什么应属于受影响成员。两层互相连接，但不相互冒充。

## 十三、可证伪规则

下列观察结果会削弱或推翻相应命题：

1. 预先定义的关键产品全部满足扩大条件，现实却长期不能形成对应分类能力增量，且不存在事前声明的组织损失；
2. 组织改革没有改变协调、信息、代理、锁定或外部化损失，却被声称提高了实现速率；
3. 持续分类速率优势在竞争可传导条件下，长期不产生任何资源、市场、人口、技术或模仿优势；
4. 强耦合提高而扩大协调边界没有降低任何瓶颈、闲置或调整时延；
5. 公有制扩大共同控制后，新增信息和代理损失持续超过减少的协调与外部化损失；
6. 地租、资本积累和重商主义只能依据事后成功与失败区分，无法在行动前按控制对象和用途分类；
7. 改变系统边界是解释反例的唯一方法，而边界未在研究前声明。

这些失败不得通过重新定义“有效”、临时扩大边界或追加未事先声明的阻断条件消除。

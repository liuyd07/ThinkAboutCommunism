# 生产循环、产能分流与所有制

> 本文件是正文写作的理论支撑材料。它把 P00—P20 与“核心再生产循环—创新重构—终端耗散”框架统一起来，不以货币收入名称代替实体产品和能力流向。

## 一、问题

生产循环形成之后，组织不仅决定怎样生产，还决定产出流向：补偿既有能力、扩大生产循环、承担不确定创新、改善成员生活，还是用于排他权和组织竞争。所有制的核心经济作用，因此不是给企业贴上公有或私有标签，而是配置两组权利：

1. 谁控制生产资料和系统瓶颈；
2. 谁决定生产能力外溢之后的剩余分流。

本理论要解释的是所有制和组织竞争，不以生产循环取代人的生活目的。生活改善可以是生产的目的，同时在生产网络拓扑上属于产出退出当前循环的一种终端分流。

## 二、基础概念

### 1. 核心再生产循环

核心再生产循环是生产活动之间的有向环。部分产出重新成为下一轮所需的生产资料或劳动能力补偿条件：

`K(t+1)=K(t)+R(t)-D(t)`

其中 `K` 是有效生产能力，`R` 是有效返回，`D` 是设备、技能、成员能力和组织关系等损耗。采矿提供自然资源输入，但矿藏本身不由生产循环再生产；采矿设备、能源、冶炼、机器制造和运输可以构成更大的生产资料循环。

这个标量公式只用于通俗表达。严格测量时，不计算全部社会产品的总增益，也不把不同产品折算为一种物质量。对当前循环先声明实际返回生产端的关键产品集合 `J_c`，再分别计算钢材、电力、机器服务、运输服务或特定技能等每一类产品在一个循环周期后的增量：

`Δq_(j,t)=b_(j,t)-a_(j,t)-d_(j,t)，j∈J_c`

与当前循环无关的产品和已经进入终端使用的产品不参加该循环增益计算。只有研究各关键节点按同一比例扩大时，才用最先成为瓶颈的产品界定平衡扩张上限；通常保留完整的分类增益向量。严格定义、外部输入分账和可证伪规则见 [生产循环可测量与制度比较框架](生产循环可测量与制度比较框架.md)。

### 2. 产能外溢与分流

本期产出可以通俗地写成：

`Y=M+E+X+C+H+W`

- `M`：补偿既有设备、劳动能力和组织条件；
- `E`：沿已知路线扩大现有生产循环；
- `X`：探索性投入，暂时退出既有循环；
- `C`：满足成员生活和最终服务的终端分流；
- `H`：战争、控制、排他权防卫等组织竞争支出；
- `W`：没有形成能力、有效信息或最终使用效果的无效损失。

这里的“耗散”是拓扑概念：产品没有返回当前生产环。它不等于浪费或低价值。`C` 可以是社会生产的目的；`X` 可能在未来重构生产环；只有 `W` 才是严格意义上的无效耗散。

严格分析中，上述符号不是互斥的支出科目，而是活动的效果维度。对活动 `a` 记录 `y_a=(m_a,e_a,x_a,c_a,h_a,w_a)`；同一医院、学校或研发项目可以同时产生能力补偿、创新、终端生活和损失效果，只有事先规定分配方法时才做加总。

### 3. 探索性耗散与创新重构

创新在当期首先占用现有产品和劳动，却没有保证形成有效返回：

`K_t → X_t`

成功创新不是简单增加原环产量，而是改变生产节点和有向连接：

`A_t → A_(t+1)`

只有经过验证、配套、部署、维护和复制，新路线才进入未来能力：

`X_t → 技术验证 → 配套部署 → K_(t+τ)`

因此创新在事前属于风险投资，在当期属于探索性耗散，在成功部署后才表现为新的生产循环或更高的有效发展速率。成功概率难以可靠测量，不能把预期收益当作已经实现的返回。失败只有在留下可复用信息并实际改变后续选择时，才形成知识返回。

### 4. 终端耗散

食品消费、居住、娱乐、艺术和其他生活服务可以作为生产循环的最终目的而退出当前生产环。它们不因“未返回”而无意义。医疗、教育、住房和照护可能同时包含终端生活效果与劳动能力补偿，应按实际功能拆分，而不是把全部生活改称生产投资。

### 5. 无效耗散和权力耗散

重复建设、无学习的失败项目、纯粹排他权防卫、战争毁损及不可恢复污染会减少可用于 `M`、`E`、`X` 和 `C` 的产品。控制支出 `H` 可以增强特定组织的竞争能力，却未必提高社会整体生产能力；局部胜出与整体进步必须分账。

## 三、所有制为什么进入生产循环

所有制是一束排除、信息、决策、任免、剩余索取、转让和损失承担权。它通过三条路径影响生产循环：

1. **节点控制**：决定谁可以使用资源、基础设施、机器、数据和接口；
2. **分流控制**：决定 `M、E、X、C、H、W` 的实际比例；
3. **风险控制**：决定创新失败、生态损耗和组织错误由谁承担。

所有制不直接创造生产力。只有权利结构改变有效返回、损耗、试验质量和纠错时间，才改变生产力发展速率。

## 四、大生产循环为何产生扩大控制边界的压力

采矿、能源、冶炼、机器制造、运输和工程知识构成强互补网络。网络服务常受最弱瓶颈限制：

`K_system≈min(k_n/c_n)`

非瓶颈节点单独扩张可能只形成闲置；多节点加价、投资等待、规格冲突和建设时序错配也会降低全环返回。因此大生产循环要求联合协调，但联合有多种制度形式：

- 企业纵向一体化；
- 跨国公司与控股网络；
- 长期合同和供应链治理；
- 行业标准与公共平台；
- 国家规划、公共投资和公有制。

跨国企业集中和长期合同说明生产循环存在扩大实际控制边界的压力，但不自动证明公有制。资本主义可以在企业产权边界内完成高度联合；问题在于其优化目标通常是自身资本增殖，未必纳入劳动者、消费者、生态和链外节点的损益。

公有制的独特潜力不是组织规模天然更大，而是把原本属于单一企业外部的收益、损耗和长期边界纳入共同权利范围。该潜力只有在成员拥有实质控制、独立信息能够进入、探索路线可以比较、错误能够退出时才实现。

## 五、三层组织结构

### 1. 共同控制层

适用于不可替代资源、自然垄断网络、系统接口、生态预算和会造成全环失效的关键瓶颈。宜共同控制资源权、容量规划、接入规则、剩余分流和长期风险，但不必由一个行政主体包办全部运营。

### 2. 协调生产层

适用于冶炼、材料、关键机器、专业运输和其他互补生产。可由公共企业、合作组织、私人企业和混合所有制共同承担，通过长期合同、共同标准、公共投资和容量安排连接。判断标准是全环失配是否下降，而非名义所有制是否统一。

### 3. 分散探索与终端实现层

创新阶段需要多路线和局部失败；终端生活产品则需要多样偏好和自主选择。企业、合作社、公共机构、非营利组织、家庭和个人均可参与。共同控制主要提供探索预算、基础设施、边界和反垄断规则，不统一每项活动。

由此不能简单写成“成环的全部公有，未成环的全部市场化”。更准确的是：系统关键性、有效耦合、外溢范围和失败传播决定共同控制范围；不确定性和偏好多样性决定分散自治范围。

## 六、创新的制度安排

创新适合“公共承担基础风险—多路线分散探索—成功后共同扩散”的组合：

1. 核心生产循环提供稳定探索预算和共同设施；
2. 相对独立团队竞争不同路线；
3. 失败限制在局部，可复用信息进入共同知识体系；
4. 成功路线验证后，由大生产循环协调标准、配套和规模部署；
5. 创新收益返回共同生产能力，避免长期封闭为排他租权。

市场风险投资可以承担部分探索，但倾向选择可独占收益的路线；统一计划可以承担长期互补项目，但容易压缩异议和放大共同错误。两者都不能单独覆盖完整创新过程。

## 七、生产力发展速率与组织竞争

### 1. 分类产品速率

对组织 `i`、循环 `c` 中的关键返回产品 `j`：

`g_(i,j)=Δq_(i,j)/q_(i,j)`

每类产品分别报告。只有技术比例要求所有关键节点同步扩大时，才把最小分类速率作为当前循环的平衡扩张上限；它不是全部产品或整体福利增长率。

### 2. 可行速率与实现速率

技术、资源和生态约束决定各类产品的可行速率 `g^F_(i,j)`；协调失配、信息、代理、锁定和冲击损失决定现实实现速率 `g^A_(i,j)`。组织形态首先影响二者之间的缺口：

`Γ_(i,j)=g^F_(i,j)-g^A_(i,j)`

这使技术条件与组织作用分开：生产技术可以提高可行上限，组织改革则可能缩小或扩大实现缺口。实际增长又会反过来改变组织规模、控制权和稀缺结构，因而二者是共同演化而非单向决定。

### 3. 能力差距、竞争转化和制度选择

持续的分类速率差首先改变能力差距。能力还要经财政、补给、市场、技术扩散、人口吸纳、防卫和联盟结构转为竞争力量，之后才可能造成模仿、改革、兼并、依附、吸收或退出。

所以“发展速率倒逼组织升级”必须分三段证明：

```text
分类能力差距变化
→ 能力转为实际竞争压力
→ 组织模仿、改革、联合、依附或退出
```

绝对存量、暴力、垄断、联盟、外部转移和制度惯性可以延迟或阻断任一环节。

生产要素稀缺性变化会改变组织收益：

- 标准化、丰富、可替代的投入有利于市场交易和分散生产；
- 稀缺、专用、不可替代的投入推动长期合同和纵向一体化；
- 自然垄断和广泛外溢提高公共控制收益；
- 可排他化的稀缺权利推动地租化；
- 高不确定性要求多路线探索；
- 技术成熟和部署强耦合要求扩大协调。

稀缺不会自然产生公有制，也可能产生私人垄断和地租。决定方向的是谁控制瓶颈、损耗能否外部化以及竞争规则怎样反馈。

## 八、积累体制的统一解释

- **地租型运动**控制不可复制或人为稀缺条件，从其他循环抽取剩余并复制排他权。地租若用于扩大生产能力，用途上转为资本积累或地租资本化。
- **重商主义型运动**优先积累一个或少数战略对象。只有这些对象持续接入完整生产资料循环时，才转化为资本积累。
- **资本积累型运动**利用可流动资本权利组织广域协作，以增殖压力推动剩余反复进入能力扩张。资本主义也会通过垄断、专利和土地控制地租化。
- **实质公有制**可能把全社会生产环的净有效速率作为直接目标；它不是天然高效，必须同时解决信息、试验、成员控制和错误退出。

瓶颈出现后，能力项目的新增回报可能下降，控制稀缺权的收益上升。若竞争继续奖励索取权，组织会地租化；若共同控制重新配置剩余，则可转向维护、创新、生态修复、终端生活和仍有真实增量的能力建设。

分类采用事前二维结构：先记录组织控制的是稀缺权、少数战略对象、可复制能力还是共同生产条件，再记录剩余实际用于维护排他权、增加战略存量、建设能力、承担探索风险还是改善生活。来源、用途和绩效分别记录，不因项目后来成功或失败而重新命名原有行为。

## 九、制度比较与规范边界

市场、私人一体化、长期合同、公共监管、合作所有、国家所有和实质社会公有，都同时具有协调收益与信息、代理、锁定或外部化成本。公有制的比较优势只有在扩大共同控制所减少的协调、地租和外部化损失，大于新增的信息、代理和共同错误损失时成立。

生产循环理论属于描述层，解释哪些循环可行、哪些组织实现速率更高以及稀缺如何改变组织压力。人的生活、民主控制、自由和代际责任属于明确声明的规范层。生产循环可以说明共同控制何时更有能力，不能单独证明社会应追求何种最终生活。

## 十一、不能直接推出的结论

生产循环理论不能单独证明：

- 所有成环产业都应由一个公共企业统一经营；
- 所有未成环活动都适合市场化；
- 公有制天然具有最高生产力发展速率；
- 组织竞争中的胜出者代表社会整体进步；
- 生活消费必须以维护劳动能力为理由才有价值；
- 创新预算的预期收益等于已经实现的生产返回；
- 资源或生态瓶颈会自然推动社会主义转型。

理论能够支持的较强结论是：

> 强互补、系统关键和外溢广泛的生产网络会推动实际控制边界扩大；当优化对象扩展到全社会生产循环时，某种实质共同控制形式才可能把全环净有效速率、成员生活和长期边界共同纳入目标。具体运营仍应根据耦合程度、不确定性和偏好多样性，在共同控制、协调生产与分散实现之间分层配置。

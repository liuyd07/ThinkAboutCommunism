# 生产循环系列文稿一致性审计

## 审计范围

审计 `发布稿/01` 至 `发布稿/12` 的叙事链、核心术语、历史案例、反例与边界。每篇均配有案例材料和反例审查；事实链接优先采用政府、档案馆、公共研究机构和同期报告。

## 主叙事链

1. 第1—3篇从城市停摆、汽车缺件和蒸汽机建立生产循环：产品必须沿有向路径返回并补偿关键投入，工业正循环还能复制生产资料。
2. 第4篇区分存量与发展速率，并把速率按关键产品分别评估；组织淘汰还须经过竞争渠道。
3. 第5篇把剩余分为维护、扩张、探索、生活、权力防卫和无效损失等复合效果，拒绝用收入名称推断用途。
4. 第6—7篇由耦合与创新阶段推导协调边界，比较市场、合同、标准、企业和公共计划，而非进行标签对决。
5. 第8—10篇用“控制对象×剩余用途”区分地租、重商主义、资本积累与资本地租化。
6. 第11篇从强耦合推出共同控制压力和公有制潜力，同时纳入信息、代理、锁定与共同错误。
7. 第12篇把物质吞吐边界与功能、生活和规范选择分开，拒绝把共产主义写成自动终点。

## 关键术语一致性

- **生产循环**：在给定边界内，生产活动形成有向环，使关键生产投入在下一周期得到合格补偿；外部资源输入另账记录，不把生态耗竭伪装成内部闭合。
- **价值与劳动**：自然物、能源和机器参与物质转化，但产品价值以把这些条件带入社会生产所需的平均人类劳动衡量；无人维护且自由取得的产品类似自然水流，不形成稀缺劳动价值。
- **生产力**：以较少社会必要劳动持续提供特定合格功能的能力，不以价格、总工时或单一产量代替。
- **发展速率**：各类关键产品一个循环周期后的净增量；没有目的与权重时不加总为天然总体指标。
- **耗散**：相对当前生产环未直接返回的产能流向，不等于无价值。生活是目的，探索可能在后期重构循环。
- **组织**：能决定准入、分工、剩余用途、监督、处置和规则修改的行动单元。
- **公有**：关键资源、标准、容量、生态预算、剩余分流、信息与规则修改等权利的实质共同控制，不等于单一法人经营。

## 全系列最强攻击与回应

1. **功能主义与胜者史观**：高生产率组织并非总胜出。系列已加入存量、暴力、联盟、垄断、进入壁垒和竞争转化条件。
2. **事后定义**：失败就说未闭环、成功就说正循环。系列要求事前声明产品类别、循环周期、技术配方、外部输入和合格标准。
3. **不可加总**：多产品物量不能形成单一结论。系列接受这一限制，只在明确目的和权重时作总体判断。
4. **技术决定论**：制度并非生产力的被动结果。系列采用双向反馈：组织影响实现速率，速率差通过竞争形成制度压力。
5. **集中主义跳跃**：耦合不能推出全产业链单一国有。系列只推出扩大共同控制边界的压力，并以制度总损失决定具体安排。
6. **把人从属于生产**：系列明确组织存活逻辑属于描述层，生活、自由和民主属于不能由生产力自动推出的规范层。

## 尚待长篇正文继续补强

- 建立跨案例的关键物量表，展示事前分类怎样实际操作。
- 增加公有、合作社、受监管私营和混合网络的同类制度比较。
- 为劳动价值、自然条件与无人化生产单设一章，避免读者把物质贡献与价值尺度混淆。
- 对殖民、战争和阶级冲突补充更多非欧美案例，检验组织竞争机制的边界。
- 在全书结尾补写独立规范论证，说明共同控制为何值得追求，而非诉诸历史必然。

## 审计结论

十二篇已形成可连续阅读的理论入口，核心命题没有出现直接矛盾。系列最重要的限定是：生产循环与发展速率解释物质能力和组织压力，不独自决定所有制形式，更不替社会决定人的目的。

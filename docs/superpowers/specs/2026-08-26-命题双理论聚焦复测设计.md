# 命题双理论聚焦复测设计

## 一、目的

对 P00—P20 进行新一轮复测。复测不再以一般历史材料证明命题“似乎正确”，而只检验命题能否进入本书的两条核心解释链：

1. 生产循环如何形成、维持、扩大、受阻或收缩；
2. 组织间生产力发展速率差如何转化为组织形态调整压力。

理论细节和公式可以在反例压力下修改，但辩论不得离开上述两条解释链。

## 二、基本选择

采用“分层双重检验”，不要求每个命题机械地同时证明两条理论。

- 定义命题负责提供生产循环、生产力、组织、控制权等不可缺少的概念，可以只证明自己是解释链的必要前提。
- 循环命题必须指出它改变了哪些生产活动之间的有向返回、有效补偿、瓶颈、时延、外部输入或外部输出。
- 组织命题除完成循环分析外，还必须解释为什么某种结构会造成组织间可持续的相对发展速率差，以及该差距怎样通过竞争传递为制度变化。
- 规范命题必须另行说明目标选择，不能把竞争中胜出直接等同于正当、先进或符合人的福利。

## 三、最小模型

设组织 `i` 在时点 `t` 的有效生产能力为 `K_i(t)`。它不是货币资本，也不是单一吨位，而是在指定产品、服务、质量、地点和期限下能够持续提供的生产能力。

在离散时间下：

`K_i(t+1) = K_i(t) + R_i(t) - D_i(t)`

其中：

- `R_i(t)` 是本期生产循环返回并转化为下一期有效能力的增量；
- `D_i(t)` 是设备、技能、成员能力、组织关系及必要生态条件的有效损耗。

有效发展速率写作：

`g_i(t) = [K_i(t+1) - K_i(t)] / K_i(t)`

两个组织的相对能力变化近似为：

`Δ ln[K_i(t) / K_j(t)] = g_i(t) - g_j(t)`

这里的关键量是持续的速率差 `g_i-g_j`，不是某一时点的绝对能力差。但绝对存量仍影响承受失败、跨越门槛、形成规模效应和等待制度调整的时间，不能删除。

## 四、组织升级的判定链

只有以下链条基本闭合，才允许说生产力发展“倒逼”组织形态升级：

1. 某种组织规则改变资源发现、决策、协作、剩余回流、维护或纠错；
2. 这种改变提高生产循环的有效返回，或降低不可恢复损耗和调整时延；
3. 改变形成相对于竞争组织可持续的有效能力增速差，而非一次性产出、资源掠夺或统计幻象；
4. 增速差改变资源取得、人口吸纳、防卫、市场覆盖、技术扩散或联盟能力；
5. 落后组织因压力而模仿、改革、联合、被兼并、被吸收或退出；
6. 新形态保留造成速率优势的关键机制，才能称为组织形态升级。

若竞争隔绝、优势不可复制、领先方无法把能力转成竞争结果，或高增速以不可持续耗竭换取，则链条中断。

## 五、每个命题的复测格式

1. **聚焦命题**：保留一句可证伪表述。
2. **在生产循环中的位置**：标明节点、流、返回路径、损耗、瓶颈和边界。
3. **速率机制**：说明命题是否以及怎样改变 `g_i`，不得用绝对产量替代发展速率。
4. **组织传导**：说明速率差怎样形成组织调整压力；不适用时明确写“不直接推出”。
5. **第一轮反方**：攻击循环映射是否成立。
6. **第一轮正方**：只修复该机制链，不补充外围案例。
7. **第二轮反方**：攻击速率差是否真实、持续、可归因。
8. **第二轮正方**：区分一次性跃升、水平效应和持续速率效应。
9. **第三轮反方**：攻击速率差到组织变迁的传导。
10. **第三轮正方**：说明竞争渠道、时滞和可观察结果。
11. **第四轮反方**：提出最强边界反例，包括耗竭型增长、隔绝竞争、制度惯性和规范目标冲突。
12. **修订结论**：保留、削弱、拆分或放弃命题，并记录不能解释的部分。

## 六、证据规则

支持材料只有在能够识别机制链时才进入正方论证。案例至少应尽量回答：

- 对比的是哪些组织和生产循环；
- 初始能力水平是否不同；
- 观察到的是水平差、一次性跃升还是持续速率差；
- 哪项组织规则改变了循环的有效返回或损耗；
- 竞争压力通过什么渠道传递；
- 落后组织是否发生可观察的形态调整；
- 是否存在资源禀赋、暴力掠夺、外部输入或统计口径等替代解释。

仅证明“某制度与高产出同时出现”的材料不得作为核心支持证据。

## 七、范围与顺序

按既有依赖顺序复测：P00—P03、P04—P06、P07—P11、P12—P16、P17—P20。每完成一个命题即更新研究文件与台账，不等待集中审查。全部完成后再做跨命题一致性审计。

本轮不重写章节正文，不扩展到与两条解释链无直接关系的价值哲学、一般政治立场或完整经济思想史。

# 中国生产网络循环发现与验证设计

> 日期：2026-08-30
>
> 状态：设计已确认，用户要求直接进入实施
>
> 研究对象：中国生产网络，基准年为2020年，跨期检验覆盖2012、2015、2017、2018和2020年。

## 一、目标

本项目不预先指定煤炭、钢铁、石化或其他产业作为目标，而是从中国实际行业投入关系中发现有向环，再检验这些环究竟是表观交易环、生产依赖环、简单再生产环、负循环、外部支持扩张环，还是内生正循环。

最终成果必须回答四个问题：

1. 中国生产网络中有哪些由数据直接支持的稳定循环核心；
2. 哪些行业边在不同年份和不同分类口径下反复出现；
3. 哪些候选环能够补偿关键投入和能力损耗，哪些只是价格、聚合、进口或偶然交易造成的表观闭合；
4. 公开资料能够把结论推进到哪一级，哪些企业交易关系仍只能作为待验证猜想。

研究遵守全书既有边界：生产循环是开放系统。矿藏、原生资源和外部可用能量不由循环自身生产；进口、废物、污染和生态损耗必须单列。循环所能复制和增强的是生产资料、劳动能力、知识、协调能力以及资源获取和加工能力。

## 二、非目标

- 不从预设的“煤—钢—机械”或“油气—炼化—化工”图出发寻找支持材料；这些名称只能在算法发现结构后用于解释。
- 不声称公开资料能够还原全国全部企业之间的发票级交易网络。
- 不把投入产出金额、销售增长、利润增长或价格上涨直接解释为生产能力增长。
- 不把最终消费全部计入生产循环。只有能够证明其维持或形成劳动能力的部分，才进入劳动再生产层。
- 不追求唯一的循环分解。循环流的数学分解可能不唯一，研究报告稳定核心和对方法敏感的候选结构。

## 三、方案比较与选择

### 方案A：全国企业交易网络

企业级增值税发票最接近真实购销网络，但企业级发票关系不公开。上市公司年报通常只披露前五大客户和供应商的合计比例，只有满足特定条件时才披露名称；招投标数据也只覆盖公开采购。因此该方案不能作为当前主路线。

### 方案B：全行业投入产出网络

投入产出表覆盖整个经济，能够在不预设产业的情况下发现中间投入网络中的有向环，并支持跨年比较。缺点是金额会受价格影响，行业聚合可能制造表观环，而且固定资本形成通常不分配到具体购买行业，会漏掉“机器设备返回生产端”的关键边。

### 方案C：纯实物工程网络

按吨、千瓦时、台套和有效产能构造产品网络，物理含义清楚，但无法覆盖全经济，也难以统一服务、设备能力和劳动再生产。

### 采用方案

采用“方案B发现结构，方案C验证正负，方案A验证具体边”的三层组合：

```text
行业全网无预设发现
→ 跨年与随机对照去伪
→ 实物、固定资本和进口数据验证
→ 年报、招投标和关联交易公告提供企业案例
```

企业级证据不足时，相关关系必须标记为推测，不得补写为已观察事实。

## 四、多层生产网络

单一投入产出矩阵不足以表达完整生产关系。本项目建立五层网络：

1. **经常性投入层**：原料、能源、运输、维修和生产服务等当期中间投入；
2. **固定资本层**：机器、厂房、管道、电网等能力建设、更新和折旧；
3. **实物流层**：煤、油、气、电、钢、化工品及其他可获得数量数据的产品流；
4. **劳动再生产层**：工资、食品、住房、医疗、教育、照护与劳动能力之间可被证实的关系；
5. **外部边界层**：矿藏、进口、原生生态资源、废物、污染和能量耗散。

行业投入产出网络负责生成候选结构；其他层负责补足投入产出表看不见的资本返回、实物约束、劳动条件和外部泄漏。所有层的边统一采用“供应者或产品来源 → 使用者”的方向。

2020年使用可获得的最细行业口径发现候选环。2012、2015、2017、2018和2020年映射到所有年份可比较的共同分类，用于检验结构持续性。原行业代码和映射关系必须保留，禁止无法追踪的人工合并。

## 五、无预设环发现方法

### 1. 构造全行业图

所有生产行业和全部正向中间投入关系进入初始网络，不设置煤炭、钢铁、石化等行业白名单，也不预先删除服务业。最终需求和外部资源不作为生产行业间的返回边。

每条行业边至少保留三种权重，不压成单一主观分数：

- 绝对交易规模；
- 该投入占采购行业全部中间投入的比例；
- 该销售占供应行业全部中间销售的比例。

### 2. 识别循环核心

先计算强连通分量。只有位于非平凡强连通分量中的节点和边才可能进入有向环。

随后在每个强连通分量中求最大循环流：

- 每条边上的循环流不得超过观察到的行业交易额；
- 每个行业进入循环部分的流量等于离开循环部分的流量；
- 目标是在上述约束下识别能够进入某种有向循环的最大交易部分。

该步骤从完整网络中寻找循环承载核心，不依赖行业名称。

### 3. 分解候选环

将循环流分解为可解释的有向环，并同时保存：

- 环中节点和边；
- 绝对流量；
- 最弱边流量；
- 买方依赖和卖方依赖；
- 环长度；
- 所属强连通分量；
- 不同分解方法中的出现频率。

循环分解可能不唯一。报告不得把某一次分解当作唯一客观结构，而应区分稳定循环核心、反复出现的边、方法敏感的候选环和孤立年份中的疑似偶然环。

### 4. 排除凑巧成环

构造保持各行业总采购、总销售和网络密度近似不变的随机对照网络，比较现实网络与随机网络中的：

- 循环流占比；
- 强连通分量规模；
- 候选环强度和长度分布；
- 关键边反复进入循环的频率。

同时进行年份打乱、行业合并与拆分、弱边阈值变化等敏感性检验。只有显著强于随机结果、跨年持续且对合理分类变化稳定的结构，才进入重点验证名单。

## 六、正循环判定闸门

任何候选环都必须逐级通过以下闸门，证据不足时停止升级：

1. **结构成环**：投入网络存在有向返回路径；
2. **生产性返回**：返回品实际维持或形成下一轮生产能力；
3. **跨期稳定**：结构在多个年份重复出现，不依赖单一年份或单一分类口径；
4. **补偿损耗**：关键返回产品能够覆盖维持投入、折旧和失配；
5. **平衡扩张**：最弱关键节点仍具有正的分类净增量；
6. **排除外部注入**：进口设备、外部资本、资源开采增加和价格上涨单列；
7. **反事实稳健**：随机网络、年份打乱、分类变化和历史冲击不能消除该结构。

对候选循环 `c`，预先声明关键返回产品集合 `J_c`。对每个 `j∈J_c` 分别记录：

- `q_(j,t)`：周期开始时可用于当前循环的有效数量；
- `b_(j,t)`：本周期形成、可返回下一周期的合格数量；
- `a_(j,t)`：维持下一周期同等活动规模所需数量；
- `d_(j,t)`：折旧、损坏和规格失配；
- `u_(j,t)`：其他组织或境外系统的净输入。

内部净增量为：

`Δq_(j,t)=b_(j,t)-a_(j,t)-d_(j,t)`

含外部输入的可用量变化另写为：

`Δq^available_(j,t)=b_(j,t)+u_(j,t)-a_(j,t)-d_(j,t)`

需要同比扩张的循环采用瓶颈规则：

`g_c=min_(j∈J_c) [Δq_(j,t)/q_(j,t)]`

投入产出金额只用于发现关系。正负判定优先采用吨、千瓦时、台套、运力、停机时间、有效产能等实物或功能单位。无法取得关键返回量、维持投入或折旧数据时，最高只能判为“生产依赖环”或“证据不足”。

## 七、结果分类

| 分类 | 判断条件 |
|---|---|
| 表观交易环 | 只有金额交易关系，未证明生产性返回 |
| 生产依赖环 | 返回品确实进入生产，但未证明能够补偿损耗 |
| 负循环 | 关键返回能力低于维持投入和损耗 |
| 简单再生产环 | 关键返回能力大体只能补偿投入和损耗 |
| 外部支持扩张环 | 可用能力增长，但主要依赖进口或其他外部净输入 |
| 内生正循环 | 扣除损耗和外部净输入后，所有关键节点可维持且瓶颈增益为正 |
| 证据不足 | 公开资料不能可靠区分上述状态 |

### 2. 证据等级

- **A级**：官方投入产出、供给使用、能源平衡和实物产量能够直接支持；
- **B级**：年报、招投标、关联交易和监管问询能够确认部分具体交易边；
- **C级**：工艺和行业结构支持，但没有实际交易数据，只能作为待验证推测。

每条边同时标记 `observed` 或 `inferred`。证据等级和观察状态是两个字段，不允许用高可靠性的工艺文献把推测边改写成已观察交易。

## 十、数据流程

```text
下载并登记原始资料
→ 校验文件哈希与表格合计
→ 统一年份和行业编码
→ 构建经常性投入网络
→ 识别强连通分量与最大循环流
→ 分解并排列候选环
→ 跨年、随机与分类敏感性检验
→ 补充固定资本、实物和进口数据
→ 搜集企业级公开交易证据
→ 逐环通过判定闸门
→ 输出支持证据、反对证据、边界和缺口
```

## 十一、异常与缺失处理

- 官方表格的行列合计不一致时停止该年份分析，记录原值、差额和处理原因；
- 不同年份行业无法可靠映射时，只进入当年细粒度发现，不进入共同口径趋势；
- 负值、调整项和无法解释的零值单独保存，不静默改为零；
- 缺少产品专属价格指数时，不对该产品给出精确实物增长推断；
- 固定资本购买行业无法直接观察时，估算边标记为 `inferred`，并给出上下界；
- 招标公告区分预算、招标、中标、合同和框架协议金额，重复公告按项目标识和文本指纹去重；
- 企业客户或供应商名称被匿名化时，不猜测主体；
- 同一集团内部交易和市场交易分别标记；
- 下载受限、需要登录或许可不清的文件只登记来源，不绕过访问控制。

## 十二、验证与测试

1. **数据守恒检查**：清洗后的投入产出矩阵与官方行合计、列合计和总投入保持一致；
2. **编码映射检查**：每个合并行业都能回溯到原年份代码，映射无悬空节点；
3. **算法合成测试**：对预先知道答案的无环图、单环图、多环图和共享边图验证强连通分量、最大循环流和分解结果；
4. **随机对照复现**：固定随机种子并保存随机化参数，结果能够重复；
5. **跨年稳健性**：同一候选核心在共同分类下计算出现频率和边保留率；
6. **分类敏感性**：比较细分类、共同分类和合理聚合下的结果；
7. **证据冲突检查**：金额增长而实物下降、国内产量增长而进口依赖上升等冲突必须进入反对证据；
8. **人工抽查**：对排名靠前及石化、煤钢等理论上重要但排名异常的结构，核对原始表格和至少一条独立来源。

## 十三、交付物

第一轮研究交付：

1. 原始来源目录及可合法保存的原始文件；
2. 五个年份的标准化行业网络及共同分类映射；
3. 2020年细粒度候选环和跨年稳定循环核心；
4. 随机对照、年份和行业分类敏感性结果；
5. 证据最强的若干候选环详细档案；
6. 每个重点环的命题、推导过程、支持证据、反对意见和适用边界；
7. 企业级已观察边与待验证猜想清单；
8. 对石化等重要行业进入或未进入高排名循环的解释；
9. 正、平、负、外部支持或证据不足的判定，以及不得下结论的数据缺口。

研究成功标准不是预定发现某个著名产业环，而是让同一套无预设方法能够：发现稳定结构、识别偶然结构、保留反例，并明确公开数据能够支持的结论上限。

# 全书命题研究实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 对第0至20章的核心命题进行可证伪化、反例优先研究、证据整理、对抗性辩论和边界修订，逐步形成可写入正文的稳定论证。

**Architecture:** 以 `docs/全书命题台账.md` 作为全书唯一命题索引，每个命题在 `资料/` 下建立独立研究目录，保存反例、支持证据、定量数据和研究结论。研究顺序按逻辑依赖推进，不按章节编号机械推进；综合章在基础命题稳定后回写。

**Tech Stack:** Markdown、项目 `book-research` 与 `book-chapter-review` skill、权威统计数据库、同行评议文献、Git。

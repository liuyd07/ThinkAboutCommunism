# 生产循环可测量框架融入实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 在不改变全书主叙事的前提下，将分类物质增量、可行速率与实现速率、组织—生产力双向反馈、制度比较和可证伪规则融入当前框架。

**结构：** 新建技术支撑材料保存严格模型；更新所有制与产能分流材料作为通俗理论接口；更新命题台账和正文提纲，使关键章节获得明确写作任务；最后做一致性审计。

**工具：** Markdown、PowerShell、ripgrep、Git。

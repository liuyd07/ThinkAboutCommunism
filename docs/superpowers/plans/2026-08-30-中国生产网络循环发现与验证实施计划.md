# 中国生产网络循环发现与验证实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从中国2012、2015、2017、2018和2020年全行业投入产出关系中无预设发现候选环，并用跨年、随机对照、实物、固定资本、进口和企业公开证据判断其是否属于正循环。

**Architecture:** 建立独立的 `analysis/production_cycles` Python 包，按“来源登记—表格解析—共同分类—循环流发现—随机去伪—证据闸门—研究报告”顺序工作。原始数据、标准化数据、算法结果和人工证据分层保存，任何推测边都不得进入已观察边字段。

**Tech Stack:** Python 3.11、pandas、numpy、scipy、networkx、openpyxl、requests、pytest、Markdown、CSV。

```python
def test_single_cycle_is_bounded_by_weakest_edge():
    edges = [("A", "B", 8.0), ("B", "C", 5.0), ("C", "A", 7.0)]
    result = maximum_circulation(edges)
    assert result.edge_flow == {("A", "B"): 5.0, ("B", "C"): 5.0, ("C", "A"): 5.0}
```

- [ ] **Step 2: 用线性规划实现最大循环流**

对每条边设置变量 `0 <= f_e <= observed_e`，用节点—边关联矩阵约束每个节点 `inflow == outflow`，目标最大化 `sum(f_e)`。使用 `scipy.optimize.linprog(method="highs")`；求解失败必须抛出含年份和强连通分量编号的异常。

- [ ] **Step 3: 实现确定性环分解**

在正循环流子图中按行业代码词典序寻找有向环，每次减去环上最弱边，直至剩余流量低于数值容差。保存环长度、节点序列、边序列、瓶颈流和总循环流份额。

`cycle_id` 使用节点序列的词典序最小循环旋转并以连字符连接；例如 `B→C→A→B` 规范化为 `A-B-C`，确保跨年匹配不受起点影响。

- [ ] **Step 4: 保存双向依赖指标**

对每条边同时计算：

```text
buyer_dependency = edge_value / buyer_total_intermediate_input
seller_dependency = edge_value / seller_total_intermediate_sales
```

排名结果保留绝对规模、两种依赖和瓶颈流，不合成为单一分数。
